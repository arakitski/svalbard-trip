# 🏔️ Экспедиция на Шпицберген (Свальбард) — Май

Интерактивный портал и полное руководство по арктической экспедиции на Шпицберген на **5 дней / 4 ночи** в начале мая для группы из 5–6 человек.

## 🌐 Живой сайт на GitHub Pages
👉 **[https://arakitski.github.io/svalbard-trip/](https://arakitski.github.io/svalbard-trip/)**

---

## 📌 Что внутри сайта:
* **✈️ Перелёты и логистика:** Стыковки Варшава (WAW) → Осло (OSL) → Лонгйир (LYR) без смены часового пояса, стратегии выкупа билетов.
* **📅 Программа по дням:** Поминутный план экспедиции (сафари на снегоходах к Вилле Фредхейм, упряжки хаски, ночёвка в ледяной пещере, сафари к моржам).
* **🧊 Уникальный опыт:** Ночёвка внутри живого ледника Ларсбреен в полярных спальниках при -4°C.
* **🏍️ Самостоятельное сафари:** Аренда снегоходов без гида в безопасном долинном коридоре.
* **💰 Интерактивный калькулятор бюджета:** Выбор размера группы (4–8 чел.), валюты (PLN, EUR, NOK) и уровня комфорта (Эконом / Стандарт / Премиум).
* **🔫 Безопасность и оружие:** Полный гайд по защите от белых медведей, европейскому паспорту оружия (EFP) и аренде карабинов в IGP.
* **🎒 Интерактивный чек-лист:** Список снаряжения и одежды с сохранением отметок в браузере.
* **🔗 Ссылки на официальные сервисы:** Visit Svalbard, прокат IGP, гиды ледяных пещер, авиакомпании.

## 📁 Структура репозитория
* `index.html` — главная страница сайта

* `flight_and_budget_plan.md` — детальный план перелётов и тайминги
* `svalbard_activities_catalog.md` — каталог всех 1- и 2-дневных активностей
